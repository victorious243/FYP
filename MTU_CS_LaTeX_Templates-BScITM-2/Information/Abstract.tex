
Security is the most important part of everything in industries or organisations, especially in IT. The modern world of Artificial intelligence comes with so many solutions, every year, new technology is born, such as automation systems now, we don’t have to manually check things to save time. AI now solves time management problems, which is why this project is about Log Monitoring Security with Artificial Intelligent Resolution. The LMS–AI is built to provide security with some features that bring a difference in IT and Cybersecurity, using this Log Monitoring system makes life easy for everyone by automating checking logs with real and providing security updates for users, you can be able to request security report of an endpoint using a web console to see what the system as detected in the monitoring process. For example, your system may be under a DDoS attack, and you won't need to be connected directly to your machine, but you can be able to be alert that the attack is happening from the console. this means you don't need a strong knowledge of IT or Cybersecurity to be able to identify what is going on in the system because the Log Monitoring Security(LMS) can be your helper by providing some security events. It is built and friendly; you can be able to create your own rules. Lack of security can impact and damage a business to running properly because of insecurity on endpoints.
